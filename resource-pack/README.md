# Ресурспак Градостроя

Ресурспак содержит два слоя графики:

- U+E001…U+E008 — исходные полноэкранные макеты для административного предпросмотра.
- U+E009 — непрозрачная пергаментная страница с деревянной рамкой. Она закрывает серую сетку сундука; клиент 26.2 рисует предметы поверх неё. Нижний инвентарь сохраняет свои предметы и получает мягкую пергаментную разметку.
- U+E00D — увеличенная декоративная обложка 208×254, выходящая за границы инвентаря только визуально. Размеры слотов и обработка кликов остаются ванильными.
- 19 квадратных предметных значков для разделов и действий книги.
- 8 широких кнопок главного меню с русскими подписями. Холст 72×72, видимая область 72×18, модель имеет расширенную 18-unit геометрию, GUI-масштаб 4 и `oversized_in_gui: true`. Кнопка занимает три кликабельных слота; прозрачные соседние предметы сохраняют подсказку.
- Собственный шрифт с фиксированными метриками выводит название города, этап, территорию, казну и жителей из серверного `CitySnapshot`. Длинные строки ограничены шириной страницы.

`./gradlew resourcePack` создаёт `ServerMineCities-ResourcePack.zip` с pack.mcmeta в корне, пригодный для клиентской проверки.

U+E001…U+E008 соответствуют MAIN, TERRITORY, PURCHASE, UPGRADES, TREASURY, RESIDENTS, MANAGEMENT, DIPLOMACY.
Для MARKET отдельного исходного макета пока нет. Рабочий экран использует общую пергаментную страницу. Формат ресурспака — [88,0], целевой клиент — 26.2.

Стиль включён по умолчанию через `visual.use-pixel-backgrounds: true`. Установите `ServerMineCities-ResourcePack.zip` у клиента и активируйте в меню «Наборы ресурсов»: так загрузятся пергаментная страница, деревянная рамка и тематические значки. Имена, описания и действия кнопок остаются серверными; подробности показываются при наведении, как в обычном GUI Minecraft.

Исходные макеты включаются только в read-only административном preview; реальные меню используют пергаментную страницу, серверные данные и кликабельные слоты.

Генераторы находятся в `tools/`: `generate_gui_page_background.ps1`, `generate_gui_button_icons.ps1` и `generate_gui_text.ps1`. Текст книги собирается в отдельный тонкий пиксельный шрифт. `preview_gui_main.ps1` делает проверочное изображение с демонстрационными данными в `build/previews/book-main.png`; это проверка геометрии, не скриншот работающего клиента.
