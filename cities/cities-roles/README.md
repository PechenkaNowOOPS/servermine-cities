# cities-roles

Реализация назначения должностей и прикладных разрешений города.

| Роль | Возможности |
|---|---|
| `RULER` | Полное управление; назначает любые нижестоящие роли. Передача только через succession при выходе. |
| `DEPUTY` | Приглашает и исключает участников ниже себя, назначает роли ниже себя, покупает территорию и повышает этап. |
| `TREASURER` | Строительство, просмотр баланса/журнала и внесение монет. |
| `BUILDER` | Строительство, внесение монет и покупка территории из казны. |
| `MEMBER` | Строительство, внесение монет и выход из города. |

Назначение через список жителей или `/smcities role <игрок> <deputy|treasurer|builder|member>` проходит `CityRoleService`.
SQLite повторно проверяет роль инициатора, иерархию цели и revision; смена роли, revision и строка `city_role_audit` фиксируются одной транзакцией.
Покупка чанков, повышение этапа, приглашения, исключение и проверка BUILD используют ту же модель разрешений в доменном слое.

Модуль включён в единый ServerMineCities JAR; отдельного plugin.yml нет. Назначаемые роли фиксированы; пользовательское редактирование набора разрешений и вывод казны остаются отдельными задачами.
