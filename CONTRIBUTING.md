# Вклад в ServerMineCities

Перед работой прочитайте [AGENTS.md](AGENTS.md), [README.md](README.md) и [ROADMAP.md](ROADMAP.md). Создавайте небольшую ветку для одной завершённой задачи и не меняйте базу Economy напрямую.

Перед отправкой изменений выполните:

```bash
./gradlew clean build
```

Для Windows используйте `gradlew.bat`. Изменения транзакций должны включать стабильный идентификатор операции, обработку повтора и проверку поведения после рестарта. GUI-изменения должны сохранять работу без ресурспака и проверять повторные клики.

PR должен описывать наблюдаемое поведение, затронутые миграции/API, команды проверки и оставшиеся ограничения. Не прикладывайте ключи, базы сервера, миры, логи или собранные файлы из `build/`.
