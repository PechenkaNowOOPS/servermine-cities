# ServerMineCities — Градострой

Модульный плагин управления городами и королевствами для Minecraft Java Edition. Игроки развивают город через книгу управления: основывают поселение, покупают территорию, управляют казной и жителями, открывают улучшения, принимают законы, торгуют и заключают договоры.

Репозиторий содержит только ServerMineCities и его клиентский ресурспак. Реализация Economy находится отдельно; для работы Cities требуется установленный **ServerMineEconomy**. В репозитории включён только compile-only контракт `Economy API`, поэтому классы Economy не дублируются в Cities JAR.

## Возможности

- Основание города с четырьмя чанками, сохранением в SQLite и проверкой доступности участков.
- Покупка соседних чанков из городской казны с проверками прав, стадии и лимита.
- Стадии Поселение → Деревня → Город → Столица → Королевство; лимиты территории 4/12/24/40/64.
- Участники, приглашения, роли и разрешения; безопасная передача руководства.
- Защита территории, настраиваемые правила PvP, взаимодействий, огня и взрывов.
- Казна, журнал, налоги, сохранённые улучшения и проверки денежных операций через Economy API.
- Дипломатические договоры и межгородской рынок.
- Книга управления с рабочими GUI-разделами, админскими инструментами и отдельным ресурспаком.

Проект активен и продолжает развиваться. Непроверенные ограничения и ближайшие этапы указаны в [ROADMAP.md](ROADMAP.md).

## Требования

- Purpur/Paper API для Minecraft 26.2.
- Java 25 для сервера и сборки.
- Установленный `ServerMineEconomy` совместимой версии.

## Сборка

В корне проекта:

```powershell
.\gradlew.bat projects
.\gradlew.bat clean build
```

Linux/macOS:

```bash
./gradlew projects
./gradlew clean build
```

Основные результаты:

- `cities/cities-plugin/build/libs/ServerMineCities-0.1.0-SNAPSHOT.jar` — единственный Cities JAR для `plugins/`.
- `build/distributions/ServerMineCities-ResourcePack.zip` — ресурспак книги управления.
- `cities/cities-api/build/libs/cities-api-0.1.0-SNAPSHOT.jar` — compile-time API для разработчиков интеграций.

Внутренние модульные JAR в папку `plugins/` не устанавливаются.

## Установка на сервер

1. Установите совместимый `ServerMineEconomy` и `ServerMineCities` JAR в `plugins/`.
2. Запустите сервер. Cities создаёт собственную базу `plugins/ServerMineCities/cities.db`.
3. Для оформленной книги установите `ServerMineCities-ResourcePack.zip` клиентам. Без пакета GUI остаётся рабочим с ванильными названиями и подсказками.
4. Настройте цены, стадии, налоги, рынок, дипломатию и защищённые зоны в `plugins/ServerMineCities/config.yml`.

Административные и диагностические команды перечислены через `/smcities` и описаны в [сценарии проверки сервера](docs/development/server-smoke-test.md).

## Структура

```text
cities/                 16 внутренних модулей и сборочный plugin-модуль
economy/economy-api/     compile-only контракты для интеграции с Economy
resource-pack/           исходники ресурспака и генераторы GUI
docs/                    архитектура, эксплуатация и концепция Градостроя
tools/                   генераторы и скрипты проверки оформления
```

`cities-plugin` собирает все Cities-модули в один серверный плагин. Economy предоставляет сервисы через Bukkit `ServicesManager`; домены не используют общие базы данных.
